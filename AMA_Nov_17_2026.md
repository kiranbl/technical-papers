# AMA Q&A - November 17th 2026.

Brief answers to the questions asked during the review.

### 1. Anoop Vantagodi – What is the difference between inheritance and composition?

- **Inheritance** means an **is-a** relationship. A `Dog` is an `Animal` and can inherit its methods.
- **Composition** means a **has-a** relationship. A `Car` has an `Engine` object and uses it.

### 2. Khushi Rani – What does `AVG()` do?

`AVG()` is an SQL aggregate function that calculates the average of numeric values in a column. It ignores `NULL` values.

```sql
SELECT AVG(salary) FROM employees;
```

### 3. Kummari Amaresh – What is an interface?

An interface defines methods that a class is expected to provide, without specifying how they work. In Python, we can use abstract base classes (`ABC`) or protocols to achieve this.

### 4. Kuppireddy Sivashankara Reddy – How do you convert a string to a list?

Use `list()` to separate a string into characters or `split()` to separate it into words.

```python
list("hello")           # ['h', 'e', 'l', 'l', 'o']
"hello world".split()   # ['hello', 'world']
```

### 5. Manish Nalumachu – How do you drop a column using `ALTER`?

Use `ALTER TABLE` with `DROP COLUMN` to remove a column from a table.

```sql
ALTER TABLE employees DROP COLUMN age;
```

### 6. Masarpu Jyothish – What do joins and subqueries do?

- **JOIN:** Combines related data from two or more tables.
- **Subquery:** A query written inside another query, usually to provide a value or set of rows for the outer query.

### 7. Mohd Saad Shaikh – What is inheritance?

Inheritance allows a child class to reuse or extend the attributes and methods of a parent class.

### 8. Moyya Naveen – Difference between compile-time and runtime polymorphism?

- **Compile-time polymorphism:** The operation is selected during compilation, such as method overloading in languages like Java.
- **Runtime polymorphism:** The method implementation is selected when the program runs, such as method overriding.

Python mainly uses runtime polymorphism and does not support traditional signature-based method overloading.

### 9. Mudrakola Sai Pavan – What is the "S" in SOLID?

**S stands for Single Responsibility Principle (SRP).** A class should have one main responsibility or one reason to change.

### 10. Neha Sunil Magadum – What is the Open/Closed Principle?

The **Open/Closed Principle (OCP)** says that software should be open for extension but closed for modification. We should be able to add new behavior without changing existing, working code.

### 11. Palepu Veerababu – What is the use of inheritance?

Inheritance helps reuse common code, avoid duplication and customize parent-class behavior in child classes.

### 12. Parameswaran R – What is method overriding?

Method overriding happens when a child class defines its own version of a method already defined in its parent class.

### 13. Pavan Kumar – When does Python decide a variable's data type?

Python determines the type of a value at runtime. Variables are dynamically typed and can refer to values of different types.

```python
x = 10       # int
x = "hello"  # str
```

### 14. Raghu B S – How do you convert a list of characters into a string?

Use the `join()` method.

```python
chars = ['h', 'e', 'l', 'l', 'o']
word = ''.join(chars)  # 'hello'
```

### 15. Shakthivel – What is multiple inheritance?

Multiple inheritance allows a child class to inherit from more than one parent class. Python uses the **Method Resolution Order (MRO)** to decide where to look for methods.

```python
class Child(Parent1, Parent2):
    pass
```

### 16. Sunkara Prasanth – What does `super()` do?

`super()` lets a child class call methods from the next class in the inheritance chain, following Python's MRO. It is commonly used to call the parent's `__init__()` method.

```python
super().__init__()
```

### 17. Varad Rajesh Barbhai – Explain abstraction.

Abstraction means showing only the essential features of an object while hiding unnecessary implementation details. For example, we use an ATM to withdraw money without knowing how its internal system works.
