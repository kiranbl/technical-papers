# Technical Review Questions and Answers

## 1. Anoop Vantagodi: Does adding a border affect the width of an element in the CSS box model?
Yes. With the default `box-sizing: content-box`, a border increases the element's total width. With `box-sizing: border-box`, the border is included within the specified width.

```css
.box {
    width: 200px;
    border: 5px solid black;
    box-sizing: border-box;
}
```

## 3. Kuppireddy Sivashankara Reddy: How do you convert a list into a string in Python?
Use `join()` when the list contains strings.

```python
letters = ["H", "e", "l", "l", "o"]
word = "".join(letters)
print(word)  # Hello
```

## 4. Manish Nalumachu: How can you create a Git commit with an earlier timestamp?
Set both the author and committer dates before committing.

```bash
GIT_AUTHOR_DATE="2026-11-20T10:00:00+05:30" \
GIT_COMMITTER_DATE="2026-11-20T10:00:00+05:30" \
git commit -m "Add changes"
```

## 5. Masarpu Jyothish: What are degree and cardinality in SQL?
- **Degree:** Number of columns in a table.
- **Cardinality:** Number of rows in a table.

For example, a table with 4 columns and 10 rows has degree **4** and cardinality **10**.

## 6. Mohd Saad Shaikh: What is `clamp()` in CSS?
`clamp()` sets a responsive value with a minimum, preferred value and maximum.

```css
h1 {
    font-size: clamp(1rem, 3vw, 2rem);
}
```

## 7. Moyya Naveen: Which attribute displays buttons on a video tag?
The `controls` attribute displays video controls such as play, pause and volume.

```html
<video src="video.mp4" controls></video>
```

## 9. Neha Sunil Magadum: Give an example of a semantic HTML tag.
`<header>`, `<nav>`, `<main>`, `<article>` and `<footer>` are semantic tags. They describe the meaning of the content they contain.

## 10. Palepu Veerababu: What is the difference between a set and a tuple in Python?
- **Set:** Unordered, mutable collection of unique elements.
- **Tuple:** Ordered, immutable collection that allows duplicate elements.

```python
numbers_set = {1, 2, 3}
numbers_tuple = (1, 2, 2, 3)
```

## 11. Parameswaran R: What is the use of the `<pre>` tag?


## 12. Pavan Kumar: What is the universal selector in CSS?
The universal selector `*` selects all elements.

```css
* {
    box-sizing: border-box;
}
```

## 13. Raghu B S: What is the purpose of the `<meta>` tag?
The `<meta>` tag provides information about a webpage, such as its character encoding and responsive viewport settings.

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

## 14. Shakthivel: What is the difference between margin and padding?
- **Margin:** Space outside an element's border.
- **Padding:** Space between an element's content and border.

## 15. Sunkara Prasanth: What is the difference between `DELETE`, `TRUNCATE` and `DROP` in SQL?
- **DELETE:** Removes rows; you can use `WHERE` to remove selected rows.
- **TRUNCATE:** Removes all rows quickly, but keeps the table structure.
- **DROP:** Removes the entire table, including its structure.

```sql
DELETE FROM students WHERE id = 1;
TRUNCATE TABLE students;
DROP TABLE students;
```
